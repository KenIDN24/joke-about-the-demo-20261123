Entry for the [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112?utm_source=github&utm_medium=readme&utm_campaign=the-joke-about-the-demo-20261123-0112) competition `the-joke-about-the-demo-20261123-0112`.

